# Data Directory

- `raw/` contains dated public-source snapshots used by the compact reproduction workflow.
- `derived/` contains analysis-ready state panels, table inputs, and figure inputs.

Run `python analysis/build_main_results.py` from the repository root to rebuild the current main-analysis outputs. See `../DATA_SOURCES.md` for official source URLs and vintages.

The source agencies retain ownership of the raw data. The repository includes the snapshots solely to make the reported calculations auditable.
