# Data Sources

This file records the official locations and vintages of the public data used in the manuscript and online appendix. Local files are snapshots retained for reproducibility.

## Main analysis

| Source | Use and vintage | Official location |
|---|---|---|
| Business Trends and Outlook Survey (BTOS) | Reported business AI use, cycles 202524-202617 | [Census BTOS data downloads](https://www.census.gov/hfp/btos/data_downloads) |
| BTOS API | Latest-cycle supplement and variable definitions | [BTOS API reference](https://www.census.gov/hfp/btos/downloads/BTOS%20API%20Reference%20Documentation.pdf) |
| County Business Patterns (CBP) | 2023 establishment counts and employment-size composition | [2023 CBP datasets](https://www.census.gov/data/datasets/2023/econ/cbp/2023-cbp.html) |
| Rural-Urban Continuum Codes (RUCC) | 2023 county classification | [USDA ERS RUCC](https://www.ers.usda.gov/data-products/rural-urban-continuum-codes) |
| Quarterly Census of Employment and Wages (QCEW) | 2025 final annual state-sector establishment composition | [BLS QCEW downloadable files](https://www.bls.gov/cew/downloadable-data-files.htm) |
| American Community Survey | 2024 ACS five-year table B15003 for bachelor's-degree share | [Census API group B15003](https://api.census.gov/data/2024/acs/acs5/groups/B15003.html) |
| County Health Rankings & Roadmaps | March 2026 supplemental analytic release for broadband access | [Data documentation](https://www.countyhealthrankings.org/health-data/methodology-and-sources/data-documentation) |
| Core-based statistical area delineations | 2023 CBSA delineation file | [Census delineation files](https://www.census.gov/geographies/reference-files/time-series/demo/metro-micro/delineation-files.html) |
| State cartographic boundaries | 2023 1:20,000,000 state boundaries | [Census cartographic boundary files](https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.2023.html) |

The broadband file is from the March 2026 supplemental analytic release. It should not be described as a 2026 County Health Rankings Annual Data Release.
